# ADR 0001：初始系统方向

状态：初始设计，随 M0/M1 验证调整。

首版实施选择已由 [ADR 0002](0002-local-first-mvp.md) 更新；本记录保留初始考虑，不代表现有技术栈。

## 背景

项目用于展示从数据工程、大模型应用向制造业务的迁移能力。开发者需要能够解释业务约束与实现取舍，并独立复现演示。

## 决策

- 以单体应用开始，划分数据、排程、决策流程和 AI 接口等模块，避免初期引入微服务、消息中间件和复杂部署。
- 后端优先考虑 Python 与 FastAPI，使用类型明确的数据模型；排程先建立规则基线，后引入 OR-Tools CP-SAT。
- 前端候选为 TypeScript 与 React；甘特图库在明确展示与拖动需求后，根据许可证和维护情况选择。
- 本地演示优先考虑 SQLite；持久化方案随版本管理和并发需求确认。
- 排程核心不依赖大模型。没有模型密钥时，仍可运行核心演示和基于模板的结果说明。
- AI 层只读取已校验的结果，通过受控工具提出操作；计划发布经过人工确认。

以上是技术方向，尚未表示依赖已经安装或实现已经完成。

## 取舍

初期不覆盖复杂工厂全部约束，不承诺生产级可用性。通过显式假设与逐步扩展场景换取可解释、可测试的完整流程。

## 后续验证

在首个业务案例确定后，核对数据模型、规则调度和版本管理的需求，再确定依赖版本与接口契约。
