# 第一阶段验收清单

## 验收目标

在本地完成一次可解释的设备故障辅助排产闭环：系统计算候选方案，展示方案差异和证据，员工做最终决定并发布。

## 演示步骤

1. 启动后端和前端，打开 `http://127.0.0.1:5173`。
2. 确认当前计划、故障事件、受影响工序和订单影响已加载。
3. 在左侧编辑设备故障，填写预计恢复时间，点击“保存事件”。
4. 点击“生成候选方案”，确认甘特图和方案比较同时更新。
5. 展开方案比较，检查指标、工序、交付、影响链、证据和假设。
6. 选择一个候选方案，填写人工理由，选择“发布”或“暂不发布”。
7. 发布后确认正式计划版本增加；暂不发布后确认正式计划不变。

## 第一阶段通过标准

- [x] 前后端分离，后端负责版本校验、候选生成和发布事务。
- [x] 甘特图和方案比较是主界面，AI 分析是辅助入口。
- [x] 候选方案不能直接改写正式计划。
- [x] 发布必须经过人工选择和理由填写。
- [x] 方案差异包含设备转移、时间调整和订单交付影响。
- [x] 未知恢复时间只提示风险，不生成正式候选。
- [x] 事件或计划版本变化时，旧候选和分析结果失效。
- [x] 离线 Agent 流程可运行；真实 API 模式读取后端环境变量。
- [x] 自动化测试、构建、架构边界检查和 CI 通过。
- [ ] 使用真实模型供应商完成一次 API 联调（需要本地配置密钥）。
- [ ] 在可用浏览器环境完成一次人工视觉检查。

## 已知限制

第一阶段使用固定仿真快照和 SQLite，尚未接入 MES/ERP、实时设备流、插单、拖拽排产和用户认证。这些属于后续阶段；项目不以 CP-SAT 或其他优化算法作为主线。
