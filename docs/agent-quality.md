# Agent 质量评分与分级处理

评分版本为 `rules-v1`，由后端确定性规则生成并在交接时复核。它表示结构化报告的规则质量，不是方案成功概率，也不替代审批与发布检查。

- 数据校验：必需数据与硬约束检查通过得 100 分；存在轻微警告得 98 分；阻断或失败得 0 分。生成链路低于 98 分立即停止。未检查条件不计为已通过。
- 排产、评估、解释：从 100 分起，每次质量修正扣 5 分；有警告或无候选结论时上限 95 分；上游有数据警告或未核验生产条件时上限 70 分。真实执行失败为 0 分。
- 顶部综合信任度为后三个 Agent 得分的算术平均值，保留两位小数。仅完成链路且数据校验至少 98 分时展示。各 Agent 得分与扣分依据在链路详情展示。
- 历史记录缺少评分时展示“未评分”，不补造分数；本轮新交接必须提供经过复核的规则评分。

缺少必需数据、引用不存在的设备/订单/模具时，数据校验状态为 `failed`，保留具体错误与修复建议。其他硬约束阻断保留 `blocked`，均停止生成链路。

轻微缺失或人员、物料等未核验条件允许继续，但最终解释摘要强制包含“⚠️ 风险提示”及具体缺失条件，同时降低评分。当前输入尚不提供完整人员、物料数据，正常演示也可能显示 70 分。

排产无候选属于业务结论：继续评估和解释，提供加班、补录有效班次后重新排产等人工决策建议。建议没有验证可行性，不伪造候选、产能收益或可发布计划。批准评估结论不产生计划发布权限。规则工具异常仍按真实失败处理。

本次评分字段为兼容性扩展，不需要重置数据库或覆盖既有业务记录。
