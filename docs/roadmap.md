# Schedule Copilot 四阶段路线

## 第一阶段：本地业务闭环（已完成）

围绕注塑车间设备故障和模具换型场景，完成规则排程、故障影响分析、候选方案比较、甘特图、证据展示和人工发布。确定性规则负责约束校验和候选结果，AI 只做辅助解释。

## 第二阶段：多 Agent 协作增强（进行中）

完善生产计划 Agent、设备资源 Agent 和决策协调 Agent，增加结构化报告、证据逐条引用、运行 trace、模型成本统计、真实模型 API 联调和失败降级。

## 第三阶段：实时制造事件接入

接入 MES/ERP 或设备事件流，处理重复、乱序、延迟和过期事件，支持多故障、紧急插单、班次、物料和模具保养等业务信息。所有变更仍由 Agent 建议、规则校验、员工确认。

## 第四阶段：可演示的制造业应用

补充多案例评估、Agent 单体与协作效果对比、审计和可观测性，增加认证、云端部署和面试演示环境。重点验证迁移能力、解释能力和人机协同流程。

项目不以 CP-SAT、数学优化器或追求理论最优解为主线。排程结果由可解释规则和校验器保证，Agent 负责证据读取、分析、协调和解释。
