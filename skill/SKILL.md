# SchedCopilot 部署 Skill

执行前完整读取 [deploy_skill.md](deploy_skill.md)，遵守其中 Checklist。

默认协助用户手动操作：区分本地 PowerShell 和服务器 Bash，提供完整、按顺序可复制的命令。每批命令说明执行位置、成功标志和失败时需要返回的输出。先查明路径与发布方式，再生成本次具体命令；不要让用户自行猜测占位符。

创建本 Skill 不授权任何服务器变更。已有明确部署授权时在范围内继续，无需重复确认；数据库替换、数据清理不属于普通代码更新。

输出以事实为准，列出 Checklist 的通过项、失败项、未验证项。只有服务器数据库、本机 API、公网 API 数据一致后才进入页面验收。不要把计划版本 V4 当作软件发布版本，也不要把无可行候选的评估审批当作可发布的排产方案。
